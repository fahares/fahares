## 📖 درباره پروژه

پروژه **فهارس (Fahares)** یک **متافهرستگان (Meta-Catalog)** یکپارچه و موتور کاوش هوشمند برای نسخه‌های خطی و اسناد مکتوب تاریخی ایران و جهان اسلام است.

برخلاف سامانه‌های سنتی تک‌مأخذی، فهارس با **معماری چندمنبعی (Multi-Catalog Architecture)** طراحی شده است؛ به این معنا که بستر داده‌ای سامانه قابلیت میزبانی، تطبیق و یکپارچه‌سازی هم‌زمان چندین فهرست مرجع و کاتالوگ‌های کتابخانه‌ای مستقل را داراست و هر اثر، نسخه خطی و ارجاع دارای پیوند مستقیم با مأخذ اصلی خود (`catalog_id`) می‌باشد.

### نخستین و بزرگ‌ترین مأخذ مستقر در سامانه:
دوره ۳۴ جلدی **«فهرستگان نسخه‌های خطی ایران (فنخا)»** به کوشش استاد **مصطفی درایتی**، به عنوان مأخذ پایه (کاتالوگ شماره ۱) به‌صورت کامل استخراج، پالایش ساختاری و در پایگاه داده بارگذاری شده است. زیرساخت پلتفرم به گونه‌ای مهندسی شده که در گام‌های آتی پذیرای سایر مراجع بزرگ (نظیر «دنا»، فهرست‌واره دایرةالمعارف بزرگ اسلامی، فهارس تفصیلی کتابخانه‌های ملی، مجلس، ملک، رضوی، مرعشی و مجموعه‌های خطی سراسر جهان) باشد.

## ✨ قابلیت‌ها و ویژگی‌های کلیدی سامانه

### ۱. معماری متافهرستگان و چندمنبعی (Multi-Catalog Architecture)
- عدم وابستگی داده‌ها به یک منبع خاص و امکان اتصال بی‌درنگ چندین کاتالوگ مستقل.
- نمایش استناد رسمی و استاندارد علمی برای هر نسخه (`citation_format`) متناسب با کاتالوگ مربوطه.
- نمایش ردیف و شماره بازیابی نسخه در مأخذ مشخص.

### ۲. موتور کاوش پیشرفته و آنی (Instant & Faceted Search)
- **محدوده‌های تفکیک‌شده جستجو (Search Scopes):**
  - *فقط در عناوین:* متمرکز بر عناوین اصلی، پیراسته و هم‌تراز آثار.
  - *فقط در عناوین و اعلام (پیش‌فرض):* جستجوی هدفمند در عناوین، نام مؤلفان و کاتبان (جلوگیری از هجوم نتایج متنی ناخواسته).
  - *در همۀ اطلاعات:* جستجوی تمام‌متن در سراسر شناسنامه، عبارات آغاز و انجام، کتابخانه‌ها، یادداشت‌ها و تملکات.
- **ناوبری فیلترهای چندبعدی پویا (Faceted Navigation):** توزیع بلادرنگ فراوانی بر اساس کتابخانه‌ها، خطوط، سده‌ها و مؤلفه‌های کالبدشناسی.
- **تطبیق هوشمند رسم‌الخط:** یکپارچه‌سازی حروف عربی/فارسی (ک، ی، ة، ه، تشدید، نیم‌فاصله) با انعطاف‌پذیری در خطاهای تایپی (Typo-Tolerance).

### ۳. کالبدشناسی عمیق نسخه‌شناسی (Rich Codicology)
- استخراج ساختاریافته آغازها و انجام‌های چندگانه (`incipits` و `explicits`) در نسخه‌های دارای چند بخش یا رساله.
- پرچم‌های بولی وضعیت تخصصی:
  - نسخه اصل / دستخط مؤلف (`is_autograph`)
  - گواهی مقابله و معارضه / بلاغ (`is_collated`)
  - تذهیب، ترصیع، سرلوح مذهب و زرین (`is_illuminated`)
  - مجدول و کادربندی اوراق (`is_ruled`)
  - نسخه مصور و نگاره‌دار (`is_illustrated`)
  - حواشی و تعلیقات مؤلف (`has_author_marginalia`)
- ثبت تفکیک‌شده مسطوره (سطح نوشته) از ابعاد کل برگ، جنس کاغذ و نوع جلد و صحافی.

### ۴. سامانه پانویس‌های انتقادی و تعامل پژوهشگران (Scholarly Annotations)
- **پیشنهاد تصحیح فیلدها (`field_suggestions`):** امکان ثبت پیشنهاد روی هر فیلد از مشخصات نسخه یا اثر همراه با الزام ارجاع به سند و منبع معتبر.
- **معماری سه‌سطحی پانویس‌ها:** حفظ ۱۰۰٪ امانت و اصالت متن منبع چاپی، اعمال مقدار صحیح در دیتابیس و نمایش نشان «پانویس انتقادی ✏️» برای محققان.

### ۵. گاه‌شماری تاریخی و مرتب‌سازی داینامیک
- محاسبه و نمایش هوشمند بازه زمانی کتابت نسخه‌های هر اثر (مثلاً «از قرن ۱۱ تا ۱۴ هـ.ق»).
- اعتبارسنجی تاریخی و پالایش نسخه‌های دارای تاریخ‌های متناقض با عصر مؤلف.
- مرتب‌سازی صعودی/نزولی جدول نسخه‌ها بر اساس تمامی ستون‌ها (ردیف، کتابخانه، بازیابی، کاتب، تاریخ، خط و برگ) در سطح کوئری پایگاه داده.

### ۶. رابط کاربری فاخر، شیشه‌ای و واکنش‌گرا (UI/UX)
- الهام‌گرفته از هویت سنتی-مدرن: پالت اختصاصی لاجوردی (`#292C56`)، طلایی کهن و زرنگار (`#B38A50`) و کاغذ عاجی (`#FEF9F3`).
- تایپوگرافی اصیل با فونت استاندارد **وزیرمتن (Vazirmatn)**.
- تم تاریک عمیق (`#0C0F1D`) و چیدمان استاندارد راست‌به‌چپ (RTL) با Tailwind CSS v4.

## 🛠️ استک و معماری فنی

- **فریم‌ورک بک‌اند:** PHP 8.3 بر بستر Laravel 13
- **پایگاه داده رابطه‌ای:** MariaDB با طراحی هیبریدی (Pragmatic 3NF + ستون‌های JSON Metadata)
- **موتور جستجوی اختصاصی:** Meilisearch v1.6 متصل از طریق Laravel Scout با متدهای بهینه‌سازی Eager Loading برای پیشگیری از کوئری‌های N+1
- **لایه فرانت‌اند:** Blade و Tailwind CSS v4 با Alpine.js
- **محیط استقرار و توسعه:** Docker و Docker Compose ایزوله، سازگار با ابزارهای مدیریت کانتینر (مانند Coolify)

## 🚀 راهنمای راه‌اندازی سریع (Quick Start)

### پیش‌نیازها
- نصب [Docker](https://docs.docker.com/get-docker/) و Docker Compose
- نصب `git` و `curl`

### ۱. کلون مخزن
```bash
git clone https://github.com/fahares/fahares.git
cd fahares
```

### ۲. پیکربندی متغیرهای محیطی
```bash
cp .env.example .env
```

### ۳. راه‌اندازی کانتینرهای داکر
```bash
docker compose up -d --build
```

### ۴. نصب وابستگی‌ها و تولید کلید
```bash
docker compose exec app composer install
docker compose exec app php artisan key:generate
```

### ۵. دریافت بسته داده‌های ۳۴ جلد (از مخزن Releases)
```bash
./scripts/download_data.sh
```

### ۶. اجرای مایگریشن‌ها و تزریق داده‌ها به MariaDB
```bash
docker compose exec app php artisan fahares:seed --fresh
```

### ۷. همگام‌سازی ایندکس‌های موتور جستجوی Meilisearch
```bash
docker compose exec app php artisan scout:sync-index-settings
docker compose exec app php artisan scout:import "App\Models\Work"
docker compose exec app php artisan scout:import "App\Models\Person"
docker compose exec app php artisan scout:import "App\Models\Manuscript"
```

سامانه روی آدرس `http://localhost:8000` آماده بهره‌برداری است.
