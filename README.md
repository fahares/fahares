# فهارس

**فهرستگان برخط و موتور کاوش نسخه‌های خطی جهان اسلام** · [fahares.net](https://fahares.net)

فهارس آثار، نسخه‌ها، پدیدآوران، کاتبان و کتابخانه‌ها را از فهرست‌های نسخه‌های خطی، کتاب‌شناسی‌ها و کتاب‌های تراجم گرد
می‌آورد و آن‌ها را به هم و به مأخذشان پیوند می‌دهد: هر نسخه به صفحه‌ی خود در فهرست کتابخانه‌اش، هر اثر به مدخل‌هایش در
کتاب‌شناسی‌ها، و هر شخص به شرح حالش در تراجم، و هر جا تصویر برگه هست، همان صفحه دیده می‌شود. هدف پوشش نسخه‌های خطی همه‌ی
جهان اسلام است. نسخه‌های کنونی سایت تقریباً همه در کتابخانه‌های ایران‌اند و فهرست‌های دیگر کشورها در راه‌اند.

پایگاه داده‌ی نسخه‌ها بر دوره‌ی ۳۴ جلدی «فهرستگان نسخه‌های خطی ایران» (فنخا) بنا شده است. متن پیراسته‌ی فنخا و پارسر آن
در مخزن جداگانه‌ی [fahares-corpus](https://github.com/fahares/fahares-corpus) است. این مخزن کد سایت است.

## داده‌ها

شمارها تقریبی‌اند و به آبان ۱۴۰۵ برمی‌گردند. شمار روز در خود سایت دیده می‌شود.

| | شمار |
| :--- | ---: |
| آثار | ۷۱٬۷۰۰ |
| نسخه‌ها | ۳۲۳٬۰۰۰ |
| اشخاص (پدیدآور، کاتب، مترجم، واقف و …) | ۶۶٬۵۰۰ |
| کتابخانه‌ها و مجموعه‌ها | ۳۶۹ |
| فهرست‌نگاران | ۱۰۷ |

| نوع منبع | منبع | جلد | نمونه‌ها |
| :--- | ---: | ---: | :--- |
| فهرست کتابخانه | ۱۵۱ | ۴۴۶ | مجلس، آستان قدس رضوی، مرعشی نجفی، ملی، ملک، دانشگاه تهران، گلپایگانی |
| کتاب‌شناسی | ۱۳ | ۷۳ | الذریعة، کشف الظنون، ایضاح المکنون، هدیة العارفین، فهرستواره‌ی منزوی، مشار |
| تراجم | ۹ | ۸۵ | طبقات أعلام الشیعة، أعیان الشیعة، ریحانة الادب، الأعلام، معجم المؤلفین |
| فهرستگان | ۲ | ۴۰ | فنخا |

متن نزدیک به ۱۱۵ هزار صفحه از این منابع در سایت است.

## آنچه سایت دارد

- **جست‌وجو** در عنوان‌ها، نام‌ها یا همه‌ی متن، با پالایش بر پایه‌ی کتابخانه، موضوع، زبان، خط، سده و ویژگی‌های نسخه. نویسه‌های
  عربی و فارسی (ي/ی، ك/ک، ة/ه، گونه‌های الف و همزه) و اعراب در جست‌وجو یکسان شمرده می‌شوند.
- **صفحه‌ی هر اثر، نسخه، شخص، کتابخانه، موضوع و فهرست‌نگار**، با ارجاع هر داده به مأخذ و صفحه‌اش.
- **منابع و تصویر برگه‌ها:** هر منبع، جلدها و صفحه‌هایش، و نمایشگر تصویر صفحه‌ی چاپی.
- **مشارکت پژوهشگران:** پیشنهاد اصلاح هر فیلد با ذکر سند، و صف‌های داوری برای داده‌هایی که ماشین ساخته است. داده‌ی ماشینی
  تا بازبینی انسانی نشان ⓘ دارد. متن مأخذ دست نمی‌خورد و اصلاح در کنار آن ثبت می‌شود.
- **پنل مدیریت** برای داوری پیشنهادها، ثبت منبع تازه و ویرایش جلدها.

## فناوری

PHP 8.3 و Laravel 13، MariaDB، Meilisearch (از راه Laravel Scout)، Blade با Tailwind CSS 4 و Alpine.js، و Vite. سایت در
Docker اجرا می‌شود. پیکربندی nginx و php-fpm نسخه‌ی پروداکشن در [`docker/`](docker/) است.

## راه‌اندازی محلی

این راه‌اندازی کد سایت و داده‌ی پایه‌ی فنخا را بالا می‌آورد. پایگاه داده‌ی سایت فراتر از این است: منابع افزوده، پیوندها و
اصلاح‌های داوری‌شده در خروجی عمومی نیستند.

پیش‌نیاز: Docker با Docker Compose، و `git` و `curl`.

```bash
git clone https://github.com/fahares/fahares.git
cd fahares
cp .env.example .env        # گذرواژه‌ها و کلید Meilisearch را عوض کنید
docker compose up -d --build
```

```bash
docker compose exec app composer install
docker compose exec app php artisan key:generate
docker compose exec app php artisan migrate
docker compose exec app sh -c 'npm install && npm run build'
```

داده‌ی پایه (JSON سی‌وچهار جلد فنخا، از ریلیز fahares-corpus) دریافت و بارگذاری، و نمایه‌ی جست‌وجو ساخته می‌شود:

```bash
./scripts/download_data.sh
docker compose exec app php artisan fahares:seed --fresh
docker compose exec app php artisan scout:sync-index-settings
docker compose exec app php artisan scout:import "App\Models\Work"
docker compose exec app php artisan scout:import "App\Models\Person"
docker compose exec app php artisan scout:import "App\Models\Manuscript"
```

سایت روی `http://localhost:8000` است. برای ساختن کاربر مدیر: `php artisan admin:create-user --email=… --name=…`.

### آزمون‌ها

آزمون‌ها پایگاه داده‌ی جداگانه‌ی `fahares_test` را به کار می‌برند:

```bash
./scripts/create_test_db.sh
docker compose exec app php artisan test
```

## ساختار مخزن

| مسیر | محتوا |
| :--- | :--- |
| `app/Console/Commands/` | فرمان‌های artisan بارگذاری، پالایش و پیوند داده |
| `app/Sources/` | ورود منابع، استخراج مدخل از متن صفحه‌ها و الگوهای ارجاع |
| `app/Http/`، `resources/views/` | کنترلرها و قالب‌های Blade |
| `database/migrations/` | ساختار پایگاه داده |
| `scripts/facsimile/` | استخراج تصویر برگه‌ها از اسکن منابع |
| `tests/` | آزمون‌های PHPUnit |
| `docs/` | مستندات (پایین را ببینید) |

## مستندات

- [`docs/PROCESS_DOCUMENTATION.md`](docs/PROCESS_DOCUMENTATION.md): گزارش گام‌به‌گام کار، در فازها.
- [`docs/TECHNICAL_APPENDIX.md`](docs/TECHNICAL_APPENDIX.md): جزئیات فنی هر گام.
- [`docs/SOURCE_PROTOCOL.md`](docs/SOURCE_PROTOCOL.md): پروتکل افزودن منبع تازه.
- [`docs/BACKLOG.md`](docs/BACKLOG.md): کارهای در صف.

## سپاس

فهارس بر دوش کار فهرست‌نگاران و کتاب‌شناسان بنا شده است: از علامه شیخ آقابزرگ تهرانی، حاجی خلیفه، اسماعیل پاشا بغدادی و
دیگر پدیدآوران کتاب‌شناسی‌ها و تراجم، تا نسل‌های فهرست‌نگارانی که گنجینه‌های خطی را یکایک فهرست کردند، و کسانی که این
فهارس پراکنده را گرد آوردند، از جمله دکتر ناصر گلباز با سایت آقابزرگ و مصطفی درایتی با دنا و فنخا. هر داده‌ی سایت با نام
مأخذ، جلد و صفحه‌اش نمایش داده می‌شود و پدیدآوران هر منبع در صفحه‌ی آن آمده‌اند.
